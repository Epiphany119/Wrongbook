# PRD：历史错题组卷记录管理与按需复原多版本导出需求规范

- **文档版本**：v1.2（同题集自动融合 + 严格版本记录）
- **创建日期**：2026-11-22
- **适用范围**：小 E 错题本（历史专项）— 错题库组卷打印、组卷记录管理页（`pages/papers`）、后端组卷状态持久化与按需实时 `.docx` 复原模块

---

## 1. 核心架构理念：「状态即文档，按需实时复原」

为避免服务器与用户手机堆积大量冗余 Word 文件，同时兼顾考前做题、考后讲评与省纸核对答案的多元化需求，本模块采用**状态驱动（State-Driven）**设计：

1. **数据库只存轻量状态，不存真实 Word 文件**：`practice_papers` 表仅记录试卷名称、关联错题 ID 列表、初始版本（`default_mode`）以及该套题实际导出过的版本集合（`used_modes`）。
2. **查看时实时复原，转发/离开后自动销毁**：后端在用户请求查看/导出时，纯内存动态拼装 `.docx` 二进制流返回；小程序写入临时文件供微信原生预览与转发后，在转发完成、离开页面或下次导出时自动清理临时 `.docx`，绝不堆积冗余文档。
3. **同题集自动融合去重与严格版本记录**：
   * 后端按去重排序后的 `question_ids` 集合作为同一套题的唯一标识；若用户用同一组错题再次组卷（例如分别导出「学生做题版」「老师做题版」「纯答案版」），系统自动融合到同一条组卷记录中并合并 `used_modes` 标签，绝不产生多条重复记录。
   * 新建组卷必须严格记录用户实际选择的版本（`parseRequiredMode` 校验），禁止无条件默认回退为「学生做题版」。
4. **动态版本标记，拒绝卡片冗余**：
   * 一套题最初只生成了「学生做题版」时，组卷记录卡片**仅展示 1 个「学生做题版」标记按钮**，点击即按该版本实时复原。
   * 当用户考后需要「老师做题版」或「纯答案版」时，点击「**其他版本 / 改名导出**」选择新版本（默认沿用初始版本与原文件名，均可按需修改）；生成新版本后，系统自动将该版本追加标记到卡片的 `used_modes` 中，后续即可一键直达对应版本。

## 2. 数据模型与接口设计

### 2.1 数据库表结构（`practice_papers`）

对应升级脚本：`database/upgrade-practice-papers.sql`（幂等可重复执行，已同步写入 `database/schema.sql`）。

| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `id` | `CHAR(36)` PK | 组卷记录唯一标识 |
| `owner_id` | `CHAR(36)` FK | 所属用户 ID（级联删除） |
| `title` | `VARCHAR(100)` | 试卷名称（默认导出文件名） |
| `question_ids` | `JSON` | 关联的错题记录 ID 有序数组 |
| `record_count` | `INT` | 勾选的错题记录条数 |
| `question_count` | `INT` | 拆平多小题后的实际总题数 |
| `default_mode` | `VARCHAR(30)` | 初始创建时选择的版本（`QUESTIONS_ONLY` / `WITH_ANSWERS` / `ANSWERS_ONLY`） |
| `used_modes` | `JSON` | 该套题已生成过的版本数组（如 `["QUESTIONS_ONLY"]`，按需动态追加） |
| `created_at` / `updated_at` | `DATETIME(3)` | 创建与更新时间 |

### 2.2 后端 REST API

| 方法与路径 | 说明 | 请求体 / 查询参数 |
| :--- | :--- | :--- |
| `POST /api/v1/practice-papers` | 保存组卷状态记录 | `{ "title": "...", "questionIds": ["..."], "mode": "QUESTIONS_ONLY" }` |
| `GET /api/v1/practice-papers` | 查询组卷记录（含 `defaultMode` 与 `usedModes`） | `?keyword=期中`（按 `title` 模糊搜索，按创建时间倒序） |
| `PUT /api/v1/practice-papers/{id}` | 修改组卷记录名称 | `{ "title": "新名称" }` |
| `DELETE /api/v1/practice-papers/{id}` | 删除组卷记录（不删除原错题） | 无 |
| `POST /api/v1/practice-papers/{id}/export` | 实时复原导出 `.docx`（自动记录新版本标记） | `{ "mode": "ANSWERS_ONLY", "customTitle": "可选自定义文件名" }` |

### 2.3 三种版本定义

| 枚举值 | 版本名称 | 导出文件名后缀 | 适用场景与内容 |
| :--- | :--- | :--- | :--- |
| `QUESTIONS_ONLY` | 学生做题版 | `-学生做题版.docx` | 纯题干与作答区，无答案，适合打印给学生练习。 |
| `WITH_ANSWERS` | 老师做题版 | `-老师做题版.docx` | 前半部分纯题卷 + 分页后附参考答案与解析，适合老师讲评。 |
| `ANSWERS_ONLY` | 纯答案版 | `-纯答案版.docx` | 紧凑横向「答案速查」+ 仅对含解析/长答案题目展开详细说明，大幅省纸。 |

## 3. 验收标准（Acceptance Criteria）

* **AC-1（单版本精简展示）**：勾选错题新建组卷并选择「学生做题版」后，进入「组卷记录」页，该卡片仅显示 1 个「学生做题版」按钮，点击即可一键复原出 `<试卷名>-学生做题版.docx`。
* **AC-2（按需切换版本 + 自动追加标记）**：点击该记录的「其他版本 / 改名导出」，改选「纯答案版」（文件名可改可不改）并导出后，卡片自动更新为展示「学生做题版」和「纯答案版」两个标记按钮。
* **AC-3（同题集自动融合）**：勾选完全相同的错题集合先后导出不同版本时，系统自动融合为同一条组卷记录并展示所有已导出版本的标签，不产生重复卡片；若仅选择「老师做题版」新建记录，卡片只显示「老师做题版」而非「学生做题版」。
* **AC-4（零文档堆积）**：后端磁盘不保存任何 `.docx` 文件；小程序端在退出「组卷记录」页、转发完成或下次导出时自动清理临时 `.docx` 文件。
