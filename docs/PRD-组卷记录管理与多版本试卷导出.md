# PRD：历史错题组卷记录管理与多版本试卷导出需求规范

- **文档版本**：v1.0
- **创建日期**：2026-11-22
- **适用范围**：小 E 错题本（历史专项）— 错题库组卷打印、组卷记录管理页（`pages/papers`）、后端组卷持久化与 `.docx` 导出模块

---

## 1. 背景与用户场景

在电子错题本的考前复习与线下打印场景中，仅支持“一次性临时导出含答案文档”存在以下明显不足：

1. **导出文件难以检索与复用**：原导出文件使用时间戳命名（如 `历史错题专项卷-1795350878318.docx`），导出后系统不保留组卷记录，下次想重打同一套错题卷时只能重新翻找勾选。
2. **不同角色与复习阶段对打印版本诉求不同**：
   * **学生自测 / 考前刷题**：需要**无答案空白卷**，避免边做边看答案。
   * **教师讲评 / 家长辅导**：需要**含答案教师版**，题卷与答案解析成套对照。
   * **考后核对答案（环保省纸）**：打印整套含题答案浪费纸张，需要紧凑排版的**纯答案省纸版**，仅保留答案速查与必要解析。

---

## 2. 功能目标

* **自定义命名**：勾选错题后支持编辑试卷名称，该名称同时作为数据库组卷记录标题、Word 正文主标题以及导出文件名（`<试卷名>-<版本>.docx`）。
* **组卷记录持久化与按名称检索**：数据库记录试卷关联的错题 ID 列表与实际拆平后的小题总数；提供独立的「组卷记录」页面，支持按试卷名称模糊查询、重命名与删除（删除记录不影响原错题）。
* **三种打印版本随时切换导出**：支持「无答案学生卷」「含答案教师版」「纯答案省纸版」三种模式；同一份组卷记录保存后，可在「组卷记录」页一键切换导出任意版本。

## 3. 数据模型与接口设计

### 3.1 数据库表结构（`practice_papers`）

对应升级脚本：`database/upgrade-practice-papers.sql`（已同步写入 `database/schema.sql`）。

| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `id` | `CHAR(36)` PK | 组卷记录唯一标识 |
| `owner_id` | `CHAR(36)` FK | 所属用户 ID（级联删除） |
| `title` | `VARCHAR(100)` | 用户自定义的试卷 / Word 文档名称 |
| `question_ids` | `JSON` | 关联的错题记录 ID 有序数组（保留原始错题引用，避免冗余复制题干） |
| `record_count` | `INT` | 勾选的错题记录条数 |
| `question_count` | `INT` | 拆平多小题后的实际总题数 |
| `created_at` / `updated_at` | `DATETIME(3)` | 创建与更新时间 |

### 3.2 后端 REST API

| 方法与路径 | 说明 | 请求体 / 查询参数 |
| :--- | :--- | :--- |
| `POST /api/v1/practice-papers` | 创建并保存组卷记录 | `{ "title": "期中中国近代史易错卷", "questionIds": ["..."] }` |
| `GET /api/v1/practice-papers` | 查询当前用户的组卷记录列表 | `?keyword=期中`（按 `title` 模糊匹配，按创建时间倒序） |
| `PUT /api/v1/practice-papers/{id}` | 重命名组卷记录 | `{ "title": "新试卷名称" }` |
| `DELETE /api/v1/practice-papers/{id}` | 删除组卷记录（不删除原错题） | 无 |
| `POST /api/v1/practice-papers/{id}/export` | 按指定版本导出可打印 `.docx` | `{ "mode": "QUESTIONS_ONLY" \| "WITH_ANSWERS" \| "ANSWERS_ONLY" }` |

### 3.3 三种导出版本排版规范

| 枚举值 | 中文名称 | 导出文件名后缀 | 排版内容 |
| :--- | :--- | :--- | :--- |
| `QUESTIONS_ONLY` | 无答案学生卷 | `-无答案学生卷.docx` | 标题、日期、总题数、姓名/得分栏 + 全局 `1..N` 纯题干（非选择题留「作答区：」），不含答案与解析。 |
| `WITH_ANSWERS` | 含答案教师版 | `-含答案教师版.docx` | 前半部分同无答案卷 + 强制分页符 + 后半部分「参考答案与解析」（`1..N` 严格一一对应）。 |
| `ANSWERS_ONLY` | 纯答案省纸版 | `-纯答案省纸版.docx` | 标题与总题数 + 紧凑横向排列的「答案速查」（如 `1. B    2. A    3. C ...`）+ 仅对含解析/订正或长答案题目展开详细说明，最大化节约纸张。 |

## 4. 前端交互流程

1. **组卷与命名导出（`pages/questions`）**：
   * 顶部操作区提供「组卷记录」与「组卷打印」入口。
   * 进入「组卷打印」勾选态后，支持单选/全选本页；点击底部「命名并导出试卷」弹出底部抽屉面板。
   * 用户可编辑试卷名称（默认预填 `历史错题专项卷 MM-DD`），三选一选择导出版本，点击「保存记录并导出 Word」即先落库保存记录，再下载 `<试卷名>-<版本>.docx` 并调用 `wx.openDocument({ showMenu: true })` 直接在微信中预览、转发或打印。
2. **组卷记录检索与复用（`pages/papers`）**：
   * 顶部提供胶囊搜索框，支持按试卷名称关键字即时检索。
   * 每张记录卡片展示试卷名、实际总题数、关联错题条数与创建时间，内置「无答案卷」「含答案版」「纯答案版」三个一键导出按钮，以及「重命名」「删除记录」操作。

---

## 5. 验收标准（Acceptance Criteria）

* **AC-1**：勾选 3 条错题（含多小题共 11 题），命名为 `期中近代史错题卷` 并选「无答案学生卷」导出，生成的 Word 文件名为 `期中近代史错题卷-无答案学生卷.docx`，正文无答案页且标题显示共 11 题。
* **AC-2**：进入「组卷记录」页，搜索 `近代史` 可精准查出 `期中近代史错题卷`；直接点击该卡片的「纯答案版」，可一键导出紧凑省纸的 `期中近代史错题卷-纯答案省纸版.docx`。
* **AC-3**：对历史记录执行「重命名」后，再次导出时 Word 正文标题和文件名均同步为新名称；执行「删除记录」后，原错题库中的错题不受任何影响。
