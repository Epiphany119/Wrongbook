## 一、已修复的代码与数据库问题汇总

### 1. 高优先级修复（阻塞性 Bug / 新环境报错）

| 编号 | 所属端 | 问题位置 | 问题原因 | 修复措施 |
| :--- | :--- | :--- | :--- | :--- |
| H-1 | 小程序前端 | `pages/practice/index.js` (`startSession`) | WXML 按钮 `bindtap="startSession"` 会把微信点击事件对象 `event` 作为首参传入 `questionId`，导致 `POST /api/v1/practice-sessions` 请求体中 `questionId` 变成 JSON 对象而非 `null`，后端反序列化直接报 **500**。 | 在 `startSession(questionId)` 入口校验 `typeof questionId === "string" && questionId.trim()`，非字符串统一置为 `null`。 |
| H-2 | 数据库 | `database/schema.sql` (`users` 表) | `DevAuthService.login()` 和 `ProfileService.get()` 均查询 `users.avatar_storage_key`，但主初始化脚本 `schema.sql` 漏掉了 `avatar_storage_key` 与 `avatar_mime_type`（仅存在于增量脚本 `upgrade-wechat-avatar.sql`），新机器建库后登录即报错。 | 已将 `avatar_storage_key VARCHAR(120) NULL` 和 `avatar_mime_type VARCHAR(80) NULL` 同步补入 `schema.sql`。 |
| H-3 | 小程序前端 | `pages/question-edit/index.js` (`onLoad`) | `loadChapters()` 仅在编辑已有错题分支调用，新建错题虽然默认锁定 `history` 学科，却从未加载历史章节列表，导致展开选填项后选不到已有章节。 | 在新建错题分支（`if (!id && history)`）补充调用 `that.loadChapters(history.id)`。 |

### 2. 中优先级修复（边界条件 / 稳定性 / 交互完善）

| 编号 | 所属端 | 问题位置 | 问题原因 | 修复措施 |
| :--- | :--- | :--- | :--- | :--- |
| M-1 | Spring Boot 后端 | `QuestionService.java` (`validate` / `validateTaxonomy`) | 校验知识点归属时，`IN (?, ?)` 占位符数量按未去重的 `pointIds.size()` 生成，但传参却做了 `.distinct()`；传入重复知识点 ID 时会报 SQL 参数数量不匹配。 | 在 `validate()` 中对 `knowledgePointIds` 去重，并在 `validateTaxonomy()` 中统一使用去重后的 `uniquePointIds`。 |
| M-2 | Spring Boot 后端 | `ApiExceptionHandler.java` (`handleUnexpected`) | 全局异常处理器吞掉了所有未预期异常的堆栈信息，发生 500 时 IDEA 控制台无报错日志。 | 引入 SLF4J `Logger`，在 `handleUnexpected` 中输出完整异常堆栈日志。 |
| M-3 | Spring Boot 后端 | `ProfileService.java` (`update` / `export`) | 年级/学期/教材版本未做长度校验，超出数据库列宽（30/30/100）会报 500；数据导出 `reviewHistory` 漏掉 `mastery_rating` 字段。 | 补充长度校验（超长返回 400 提示）、使用 `CAST(? AS JSON)`，并在 `export()` 中补齐 `r.mastery_rating`。 |
| M-4 | 小程序前端 | `utils/api.js` (`upload` / `downloadAttachment`) | 普通 `request()` 支持 HTTP 401 自动刷新 Session 重试，但图片上传和附件下载缺少 401 重试逻辑。 | 为 `upload()`、`downloadAttachment()` 及新增的 `downloadPaper()` 全部补充 401 自动续期并重试机制。 |
| M-5 | 小程序前端 | `pages/question-edit/index.js` & `index.wxml` | 恢复编辑草稿时可能覆盖服务端最新 `version`；已选知识点标签无法点击取消。 | 恢复草稿时保留服务端 `version` 兜底；新增 `removeKnowledgePoint` 支持点击标签（`×`）移除知识点。 |
| M-6 | 小程序前端 | `pages/profile/index.wxml` | 年级/学期/教材版本缺少 `maxlength`；微信昵称自动填充在部分真机只触发 `bindblur`。 | 补充 `maxlength`（30/30/100）和 `bindblur="onFieldInput"`。 |

## 二、历史专项产品级功能升级（对标市面主流错题本 & PK 四大指标）

### 1. 极速录题升级（对应 PK 第一项：OCR + 首页美观 + 快）
* **单图框选裁剪**：在首页快速拍题（`pages/home/index.js`）与录题页选图（`pages/question-edit/index.js`）中，单张选图自动调用微信原生 `wx.cropImage` 框选单道历史题（不支持或取消时自动回退原图），有效过滤整页试卷干扰文字。
* **OCR 自动预填题型与考点标签**：升级 `QuestionImageRecognitionService.java` 与 `QuestionImageRecognitionResponse.java`，DeepSeek 视觉模型在提取「题干 / 标准答案 / 解析」的同时，自动识别历史题型（选择题、材料分析题、填空题、简答题、论述题、其他）与 1–3 个核心历史考点标签，前端自动预填到表单中。
* **开箱即用的历史教材章节与核心考点库**：新增幂等升级脚本 [upgrade-history-seed.sql](file:///Users/epiphany/Files%20From%20d.localized/SomeWorks/%E6%9C%AC%E7%A7%91%E5%A4%A7%E4%B8%89%E8%B5%84%E6%96%99/%E8%B4%BA%E5%8D%AB%E5%9B%BD-%E8%BD%AF%E4%BB%B6%E9%A1%B9%E7%9B%AE%E7%AE%A1%E7%90%86/%E9%94%99%E9%A2%98%E6%9C%AC-%E5%90%8E%E7%AB%AF/database/upgrade-history-seed.sql) 并同步写入 `schema.sql`，预置中国古代史、中国近现代史、世界史共 **12 个常用历史单元**与 **30 个高频考点**，新用户无需手动建目录。

### 2. 练习闭环升级（聚焦历史专项 + 主观题闪卡免打字）
* **彻底聚焦历史专项**：移除练习页原有的 9 学科下拉框，改为**历史章节筛选** + **练习范围胶囊切换**（`全部未归档` / `到期优先` / `最近 7 天`），放开原先写死的 7 天限制，让 `{1, 3, 7, 14}` 天艾宾浩斯复习算法真正发挥作用。
* **历史主观题/材料题闪卡模式**：保留文字输入框作为选填，允许学生心里构思或在草稿纸作答后直接点击「**我已思考，查看参考答案**」对照答案并进行五档掌握度自评，彻底解决手机小屏强迫打字几百字的别扭感。

### 3. 历史学情统计看板（对应 PK 第三项：给家长和老师看）
* 后端 `DashboardService.java` 在 `/api/v1/dashboard` 聚合返回 `masteryBreakdown`（未归档/新收录/待复习/已通过/总体通过率）、`weakChapters`（薄弱历史章节 Top 5）与 `errorReasonStats`（高频错因 Top 5）。
* 首页 `pages/home` 新增「**历史学情统计**」可视化卡片，通过极简进度条清晰展示掌握率、薄弱章节排行与高频错因分布，家长和老师一眼就能看懂学习状态。

### 4. 一键组卷与导出可打印试卷（对应 PK 第四项：生成题目、打印）
* 后端新增 `PracticePaperService.java` 与接口 `POST /api/v1/practice-sessions/paper`，使用纯 JDK `ZipOutputStream` 生成标准 `.docx` 历史专项练习卷（零新增第三方依赖）：前半部分为干净的纯题卷与作答留白区，分页后附完整的参考答案、订正思路与解析。
* 错题库 `pages/questions` 新增「**组卷打印**」模式：勾选任意错题（或全选本页）→ 一键生成并调用微信原生 `wx.openDocument({ showMenu: true })` 直接在微信内预览、转发给家长/打印店或连接打印机打印。

## 三、前端视觉与交互重构（Material Design 3 极简风格）

* **全局统一设计系统（`app.json`、`app.wxss` 及全部 8 个页面）**：采用通透 `#F8FAFD` 画布 + `#FFFFFF` 纯白卡片 + `1rpx solid #E3E7EE` 精致细描边 + `#0B57D0` 沉稳主色与 `#F0F4F9` 胶囊控件，去除旧式蓝紫渐变与厚重投影，提升长段历史题干的字号与行高。
* **错题库高频体验优化**：将原本常驻占满半屏的多维筛选面板改为可折叠抽屉，首屏直接聚焦错题内容，检索与归档操作更轻快。

## 四、本地运行更新与提交前注意事项

1. **已有数据库请执行一次历史章节预置脚本**：如果你电脑上的 MySQL 之前已经建过库，请在 MySQL 客户端运行一次 `错题本-后端/database/upgrade-history-seed.sql`（幂等可重复执行），即可在录题页、错题库和练习页立刻看到 12 个历史单元与 30 个核心考点。
2. **安全必做**：`application-local.yml` 中仍保留着你当前的 DeepSeek API Key（方便你现在在 IDEA 直接跑通演示），打包交作业或推 Git 前务必去 DeepSeek 控制台轮换并移除明文 Key，同时在 `.gitignore` 中忽略 `application-local.yml` 和 `target/`。
3. **演示网络**：换热点或换教室网络时，记得用 `ipconfig getifaddr en0` 获取电脑新 IPv4 并更新 `错题本-微信小程序前端/utils/config.js` 里的 `apiBaseUrl`。
