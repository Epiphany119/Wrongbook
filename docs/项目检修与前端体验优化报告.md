- **检修日期**：2026-11-22
- **检修范围**：Spring Boot 后端（`错题本-后端`）、MySQL 数据库脚本（`错题本-后端/database`）、微信小程序前端（`错题本-微信小程序前端`）

## 一、已修复的代码与数据库问题汇总

### 1. 高优先级修复（阻塞性 Bug / 新环境报错）

| 编号 | 所属端 | 问题位置 | 问题原因 | 修复措施 |
| :--- | :--- | :--- | :--- | :--- |
| H-1 | 小程序前端 | `pages/practice/index.js` (`startSession`) | WXML 按钮 `bindtap="startSession"` 会把微信点击事件对象 `event` 作为首参传入 `questionId`，导致 `POST /api/v1/practice-sessions` 请求体中 `questionId` 变成 JSON 对象而非 `null`，后端反序列化直接报 **500**。 | 在 `startSession(questionId)` 入口校验 `typeof questionId === "string" && questionId.trim()`，非字符串统一置为 `null`。 |
| H-2 | 数据库 | `database/schema.sql` (`users` 表) | `DevAuthService.login()` 和 `ProfileService.get()` 均查询 `users.avatar_storage_key`，但主初始化脚本 `schema.sql` 漏掉了 `avatar_storage_key` 与 `avatar_mime_type`（仅存在于增量脚本 `upgrade-wechat-avatar.sql`），新机器建库后登录即报错。 | 已将 `avatar_storage_key VARCHAR(120) NULL` 和 `avatar_mime_type VARCHAR(80) NULL` 同步补入 `schema.sql`。 |
| H-3 | 小程序前端 | `pages/question-edit/index.js` (`onLoad`) | `loadChapters()` 仅在编辑已有错题分支调用，新建错题虽然默认锁定 `history` 学科，却从未加载历史章节列表，导致展开选填项后选不到已有章节。 | 在新建错题分支（`if (!id && history)`）补充调用 `that.loadChapters(history.id)`。 |

### 2. 中优先级修复（边界条件 / 稳定性 / 交互完善）

| 编号 | 所属端 | 问题位置 | 问题原因 | 修复措施 |
| :--- | :--- | :--- | :--- | :--- |
| M-1 | Spring Boot 后端 | `QuestionService.java` (`validate` / `validateTaxonomy`) | 校验知识点归属时，`IN (?, ?)` 占位符数量按未去重的 `pointIds.size()` 生成，但传参却做了 `.distinct()`；传入重复知识点 ID 时会报 SQL 参数数量不匹配。 | 在 `validate()` 中对 `knowledgePointIds` 去重，并在 `validateTaxonomy()` 中统一使用去重后的 `uniquePointIds` 生成占位符和参数。 |
| M-2 | Spring Boot 后端 | `ApiExceptionHandler.java` (`handleUnexpected`) | 全局异常处理器吞掉了所有未预期异常的堆栈信息，发生 500 时 IDEA 控制台无任何报错日志，排错困难。 | 引入 SLF4J `Logger`，在 `handleUnexpected` 中输出 `log.error("Unhandled exception on {} {}", method, uri, error)`。 |
| M-3 | Spring Boot 后端 | `ProfileService.java` (`update` / `export`) | 1) 年级/学期/教材版本未做长度校验，超出数据库列宽（30/30/100）会直接报 500；2) 数据导出 `reviewHistory` 漏掉了新加的 `mastery_rating` 字段。 | 补充长度校验（超长返回 400 友好提示）、使用 `CAST(? AS JSON)`，并在 `export()` 中补齐 `r.mastery_rating`。 |
| M-4 | 小程序前端 | `utils/api.js` (`upload` / `downloadAttachment`) | 普通 `request()` 支持 HTTP 401 自动刷新 Session 重试，但图片上传（拍照识题/附件/头像）和附件下载缺少 401 重试逻辑，Token 失效后图片功能直接失败。 | 为 `upload()` 和 `downloadAttachment()` 均补充 401 自动 `refreshSession()` 并单次重试的机制。 |
| M-5 | 小程序前端 | `pages/question-edit/index.js` & `index.wxml` | 1) 编辑已有错题恢复本机草稿时，若草稿 `version` 为空会覆盖服务端最新 `version`；2) 已选知识点标签缺少移除交互。 | 恢复草稿时保留服务端 `version` 兜底；新增 `removeKnowledgePoint` 方法，支持点击已选知识点标签（`×`）取消关联。 |
| M-6 | 小程序前端 | `pages/profile/index.wxml` | 年级/学期/教材版本输入框缺少 `maxlength`；微信昵称 `type="nickname"` 仅监听 `bindinput`，部分真机自动填充昵称时只触发 `bindblur`。 | 补充 `maxlength`（30/30/100）与 `bindblur="onFieldInput"`。 |

## 二、前端视觉与交互体验优化（Material Design 3 极简风格）

针对原界面“视觉杂乱、渐变廉价、字号偏小、筛选区过重”的痛点，在不改变任何页面功能与接口调用的前提下，对小程序全局与全部 8 个页面进行了统一视觉与交互升级：

1. **统一全局设计语言（`app.json`、`app.wxss`）**
   - 画布升级为通透的 `#F8FAFD` 浅灰白底 + `#FFFFFF` 纯白卡片，去除厚重模糊投影，改用 `1rpx solid #E3E7EE` 精致细描边与 `28rpx`–`32rpx` 大圆角。
   - 主色统一为沉稳耐看的 `#0B57D0`（Google Blue），辅以 `#F0F4F9` / `#EDF2FA` 柔和胶囊容器，按钮全面升级为现代感更强的胶囊圆角（`border-radius: 999rpx`）。
   - 全局正文字号与行高优化（次要信息提升至 `22rpx`–`24rpx`，题干行高提升至 `1.7`–`1.75`），阅读长段历史材料题更轻松。

2. **首页（`pages/home`）—— 突出“美观清晰 + 快捷录题 + 统计数据”**
   - 去除顶部卡片的旧式蓝紫渐变，改为纯白卡片搭配淡蓝描边与高对比度胶囊主按钮，拍照/相册收录入口一眼聚焦。
   - 今日练习卡片与近 7 天正确率 / 重复错题两栏统计卡片层次分明、数字醒目，更适合向老师与家长直观展示学习数据。

3. **错题库（`pages/questions`）—— 筛选栏改为可折叠，检索更顺手**
   - 搜索框升级为极简胶囊搜索栏（`#F0F4F9`）。
   - 将原本常驻占满半屏的多维筛选面板（标签、章节、错因、排序、日期范围、只看待复习开关）改为**可折叠抽屉**，默认只保留搜索栏 + 状态胶囊 +「筛选」切换按钮，大幅提升错题列表的首屏可视面积，同时保留 100% 筛选能力。

4. **录题页、详情页、练习页与个人中心（`question-edit` / `question-detail` / `practice` / `profile` / `trash` / `feedback`）**
   - **录题页**：输入框改为 `#F0F4F9` 柔和圆角输入区，新增图片按钮改为淡蓝虚线框，支持点击移除已选知识点标签。
   - **详情页**：题干采用纸感排版，底部「参考答案」弹窗升级为 `36rpx` 大圆角抽屉。
   - **练习页**：去除结题页的蓝紫渐变背景，改为高级感的 `#EDF2FA` 柔和色块 + 醒目主色得分；选择题选项与五档掌握度评分按钮加大触控区域，选中/答对/答错反馈色语义清晰（绿 `#137333` / 红 `#B3261E` / 蓝 `#0B57D0`）。
   - **个人中心 / 回收站 / 意见反馈**：全面对齐统一卡片描边、胶囊按钮与间距规范。

## 三、待人工确认与答辩/提交前注意事项（未强行改动，保障本地正常运行）

1. **【安全必做】提交代码或推送 Git 前清理明文 DeepSeek API Key**
   - `错题本-后端/src/main/resources/application-local.yml` 中当前仍保留着你的真实 DeepSeek API Key（为了不影响你现在在 IDEA 直接运行演示，本次未删除）。
   - **强烈建议**：打包交作业或推 GitHub/Gitee 前，在 DeepSeek 控制台吊销/轮换该 Key，并将 `application-local.yml` 改为环境变量注入（`api-key: "${DEEPSEEK_API_KEY:}"`），同时在 `.gitignore` 中忽略 `application-local.yml` 和 `target/` 目录。
2. **【跨机运行】存储路径与局域网 IP**
   - `application.yml` 中的 `app.storage.location` 默认指向你本机 Mac 绝对路径，换电脑部署时可通过环境变量 `APP_STORAGE_LOCATION` 覆盖，或改为相对路径 `./uploads`。
   - `错题本-微信小程序前端/utils/config.js` 中的 `apiBaseUrl` 为局域网热点 IP（`http://172.20.10.3:8080/api/v1`），答辩现场切换网络后请用 `ipconfig getifaddr en0` 获取新 IP 并更新。
3. **【产品策略确认】练习页 7 天范围与学科范围**
   - 目前首页、错题库、录题页均已聚焦「历史专项」，而练习页下拉框仍列出全部 9 个学科，且后端 `PracticeService.start()` 固定 `recentOnly = true`（仅抽最近 7 天收录的错题）。如果答辩时需要演示超过 7 天的错题复习或聚焦历史，可在 `PracticeService.java` 第 44 行将最后一个参数 `true` 改为 `false`。
4. **【工程规范】Maven `groupId` 与单元测试**
   - `pom.xml` 中 `<groupId>com.xuotiben</groupId>` 与 Java 包名 `com.cuotiben` 有一字之差，不影响运行；答辩前建议在 `src/test` 下补 2–3 个核心测试类（如 `ReviewSchedulePolicy` 间隔计算、`QuestionService` 增删改查），并确保每个 Java 类都有简洁的类级中文注释（贴合课程要求）。
